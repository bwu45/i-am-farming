# I Am Farming

A 2D farming RPG built in Unity with C#.

## About

This is a top-down farming game where you plant and grow crops, manage your farm, and explore. I'm building it to learn Unity and C# game development from the ground up.

## Built With

- Unity [version, e.g. 6000.0.x LTS]
- C#
- Git + Git LFS for version control
